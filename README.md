# Lomamatkat - Simple Static Webpage

## About This Project
This repository contains a very basic, introductory web development project. It is a simple static webpage focused on a travel or holiday theme ("Lomamatkat"), created to practice fundamental HTML structure and CSS styling.

## Repository Contents
* **`loma.html`**: The main HTML file containing the structure and content of the travel page[cite: 9].
* **`loma.css`**: The stylesheet used to format and style the HTML elements[cite: 9].
* **Images**: Visual assets used on the page, including `kreikka.jpg`, `lomamatkat.png`, and `lomamatkat-logo.png`[cite: 9].

* HTML
* CSS
